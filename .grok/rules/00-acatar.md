# Órdenes de pie (cada turno)

El usuario **no** tiene que recordarte las reglas. Si estás en este repo, ya aplican.

1. **Acata** `.grok/rules/invariantes.md` (`INV-01` … última `INV-NN`) en **cualquier** pedido: diseño, código, copy, media, commit, “solo mira”, “arranca el server”. Son órdenes, no scripts.
2. **No esperes** la frase “acata las invariantes”, “sigue las rules” o “haz el INV”. Eso ya está dicho aquí.
3. `npm run lint` / `typecheck` / `build` **no** cumplen una invariante. Solo comprueban una parte.
4. Al **cerrar** trabajo de producto: commit con la skill `.grok/skills/commit` y declaración de obediencia. El hook solo verifica el juramento.
5. Si una necesidad estable del producto no tiene `INV-NN`, **añádela** y cúmplela en el mismo cambio.
